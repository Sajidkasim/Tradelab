Credit: Human Reference Atlas contributors; geometry informed by Allen Human
Reference Atlas (Ding et al., 2016) and the Visible Human Project. Consult the
source entry for the complete bibliography. The source describes 141 anatomical
structures mirrored to form a whole brain and resized for Visible Human bodies.
The v1.3 entry explicitly licences the model CC BY 4.0.

Primus changes presentation only: neutral materials, regional highlighting,
transparency, hemisphere visibility, camera views and original educational copy.
Frontal-pole highlighting is a landmark, not full prefrontal-cortex segmentation.
No Neurotorium assets or editorial content have been copied. This model is an
educational reference, not a diagnostic tool or a simulation of brain activity.

`assets/brain-preview.png` is a Primus-rendered screenshot of the same model,
with frontal-pole highlighting and neutral materials. It retains the attribution
and CC BY 4.0 licence of the underlying model; it is not a medical scan.
